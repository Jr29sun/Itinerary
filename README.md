# 开封五日攻略

2026 年国庆开封行程页面,10.2 周五 17:00 抵达,10.6 周二 14:00 结束。

在线访问:https://jr29sun.github.io/Itinerary/

整个页面是一个独立的 `index.html`,不依赖构建工具,手机浏览器直接打开即可使用。

## 功能

- **行程**:按天查看安排,每一项可勾选完成。行程内容由组织者在 `itinerary.json` 里统一更新,所有人同步。
- **地图**:用示意图标出 10 个景点,橙色表示待打卡,青绿色带勾表示已打卡。点景点可直接打卡,和行程里的勾选同步。
- **待办**:出发前的准备事项,可添加、勾选、删除。
- **复制全文**:把整份行程复制成文字,方便发到微信群。
- **刷新行程**:重新读取最新的行程。

## 使用说明

- 行程内容所有人同步;打卡勾选和待办只保存在**当前设备的浏览器**里,不会同步给其他人。
- 清除浏览器数据会丢失本机的打卡和待办记录。
- 地图是示意图,方位和远近为大致情况,不是精确比例,导航请使用手机地图 App。
- 地图按行程里的景点名称匹配打卡状态,修改 `itinerary.json` 时请保留景点名称,否则联动可能失效。

## 更新行程

行程数据放在 `itinerary.json`,页面每次打开都会读取它,所有人看到的是同一份。

1. 在仓库里打开 `itinerary.json`,点右上角铅笔图标编辑。
2. 修改时间、地点或备注(格式为 `["时间", "地点", "备注"]`),注意保留英文引号和逗号。
3. 点 Commit changes 提交,等一两分钟。
4. 同伴点页面底部「刷新行程」,或重新打开页面,即可看到最新版。

## 文件结构

```
.
├── index.html       # 攻略页面(行程、地图、待办)
├── itinerary.json   # 行程数据(修改这个文件来更新行程)
└── README.md        # 项目说明
```

## 部署

使用 GitHub Pages,从 `main` 分支的根目录发布:仓库 Settings → Pages → Source 选择 Deploy from a branch,分支选 `main`,目录选 `/ (root)`。
